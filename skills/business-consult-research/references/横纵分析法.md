# 横纵分析法（卡兹克方法改编）

> 用于 AI 机会地图 Skill 的 **Stage 1（基本面分析）** 和 **Stage 2（商业模式拆解）**。
> 基于卡兹克的横纵分析法改编，融入"为 Stage 3 使用者痛点研究做铺垫"的视角导入。

---

## 方法概述

两条核心轴：

- **纵向轴（时间深度）**：从行业诞生到当下的完整演进，理解"为什么是今天这样"
- **横向轴（同期广度）**：当下时间点的同赛道玩家对比，理解"在生态里的位置"

**关键**：两轴交叉看，才能下判断。

---

## Stage 1 — 纵向分析（5 个维度）

### 1. 起源追溯
- 行业诞生的背景（社会需求 / 技术变革 / 监管放开 / 资本流入）
- 早期技术理念 / 商业模式雏形
- 第一批入局者（人 / 公司 / 事件）
- 当时所处的更宏观环境（年份、社会、经济、技术大势）

### 2. 诞生节点
- 公认的"行业元年"是哪一年？为什么？
- 标志性产品 / 公司 / 事件
- 最初的形态和定位

### 3. 演进阶段
按时间顺序梳理 **3-5 个关键阶段**，每个阶段：
- 起止时间
- 标志事件（产品发布 / 融资 / 监管 / 技术突破）
- 商业模式变化
- 玩家阵营变化
- 用户规模 / 市场规模里程碑
- 这个阶段的"主旋律"是什么

### 4. 关键转折
- 转折事件（什么让行业从 A 走到 B）
- 谁推动了转折
- 转折后哪些玩家死了，哪些玩家活了
- 转折给行业留下的"现在还在影响"的遗产

### 5. 当下阶段
- 行业现在处于哪个阶段（萌芽 / 增长 / 成熟 / 衰退 / 重塑）
- 当下最大的张力是什么（监管 / 技术 / 资本 / 用户）
- 接下来 1-2 年的可见趋势

---

## Stage 2 — 横向分析（4 个维度）

### 1. 核心玩家对比
列出 **5-10 个代表玩家**，至少 4 个维度对比：
- 商业模式
- 技术路线
- 用户规模 / 市场份额
- 差异化定位
- 是否上市、融资进度

**特别要求**：玩家分类至少 3 档（头部 / 中部 / 长尾），不要只看头部。

### 2. 商业模式拓扑
- 这个行业有几种主流商业模式？（C 端订阅 / B 端 SaaS / 服务费 / 广告 / 分成 / 一次性）
- 每种商业模式服务什么使用者？
- 哪些环节是核心利润点？
- 哪些环节是成本黑洞？
- 不同商业模式的玩家如何共存？

### 3. 价值链拆解
按上游 → 中游 → 下游：
- 每段做什么（功能）
- 每段的代表玩家
- 每段的关键资源（数据 / 人 / 渠道 / IP / 工具）
- 每段的利润率水平
- 每段对其他段的依赖关系

**【核心环节】标记**：
明确标记 **哪些环节是利润核心 / 哪些环节是成本核心**，这是 Stage 3 痛点研究的入口。

### 4. 生态位与趋势
- 当下生态位竞争激烈点在哪？（红海区域）
- 增量空间在哪？（蓝海区域）
- 政策 / 监管对生态位的影响
- 3 年内最可能的颠覆性变化

---

## 两轴交叉判断（4 个必答问题）

完成纵向 + 横向后，回答以下 4 个问题：

1. **纵向看，行业有什么"必然规律"是横向必须遵守的？**
   - 例：所有内容平台都遵循"补贴 → 退坡 → 头部化"路径
   
2. **横向看，当下生态有什么"反常"是纵向无法解释的？**
   - 例：用户画像突变、新进入者超速增长、传统玩家失速

3. **哪些玩家踩在了纵向"正确节奏"+ 横向"好生态位"的双重红利上？**
   - 这些是值得深入研究的"教科书案例"

4. **接下来 1-2 年，纵向 + 横向交汇会出什么新机会？**
   - **这 3-5 个机会就是 Stage 3 的种子**

---

## 输出要求

整理成 Markdown 文档，含：
- 纵向 5 维分析（每维一段，含数据 + 信源 URL）
- 横向 4 维分析（每维一段 + 表格对比 + 价值链图）
- 两轴交叉的 4 个问题答案
- **【核心环节】明确标记**（为 Stage 3 衔接）
- **【AI 机会种子】3-5 个**（为 Stage 3 衔接）

分别写入 `research/03-s1-foundations.json` 与 `research/04-s2-business-model.json`，再由 S6 合成报告。

---

## 调用方的注意事项

- 每个数据必须有信源 URL
- 数据不足时明确标注"信息不足"，不允许编造
- 关键玩家的对比建议用表格而不是流水账
- 价值链图建议用 Markdown 表格 + 文字描述（Obsidian 不直接渲染 Mermaid，但可用代码块）
